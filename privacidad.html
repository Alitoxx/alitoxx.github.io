PrivacidadPrivacy

Este sitio no tiene analítica, no usa cookies de seguimiento y no carga recursos de terceros. No hay formularios: el único canal es el correo.This site has no analytics, no tracking cookies and no third-party resources. There are no forms: the only channel is email.

Qué guarda tu navegadorWhat your browser stores

Una sola entrada en localStorage: el idioma que elegiste (alexis-lang). Es tuya, se puede borrar vaciando los datos del sitio y no se envía a ningún servidor.A single localStorage entry: the language you chose (alexis-lang). It is yours, it can be deleted by clearing site data, and it is never sent to any server.

Qué guarda el servidorWhat the server stores

El sitio es estático. El proveedor de hosting puede registrar la petición (IP, ruta, fecha y agente) como cualquier servidor web, según su propia política. No hay base de datos de visitantes.The site is static. The hosting provider may log the request (IP, path, date and user agent) like any web server, under its own policy. There is no visitor database.

CorreoEmail
